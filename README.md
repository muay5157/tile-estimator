# ประเมินค่าปูกระเบื้อง (โปรโตไทป์)

เว็บหน้าเดียวให้ลูกค้าประเมินช่วงค่าแรงปูกระเบื้องด้วยตัวเอง แล้วเห็นเหตุผลเป็นภาษาธรรมดา ทำไว้เป็นตัวอย่างสำหรับคุยกับช่างผู้รับเหมา ไม่ใช่ระบบเสนอราคาจริง

ใช้ได้บน **GitHub Pages** เพราะเป็น HTML / CSS / JavaScript ล้วน ไม่มีขั้นตอน build และไม่มีเซิร์ฟเวอร์

## สิ่งที่ควรรู้ก่อนใช้

- ตัวเลขทุกตัวเป็น **ราคาตัวอย่าง** แถบข้อความ `ราคาตัวอย่าง ยังไม่ใช่ราคาจริง` จะโชว์ตลอด
- ชื่อร้าน `ช่างกระเบื้อง (ชื่อร้านตัวอย่าง)` และเบอร์ `08x-xxx-xxxx` เป็นค่าจำลอง ยังโทรไม่ได้
- ยอดที่แสดงเป็น **ค่าแรงอย่างเดียว** ยังไม่รวมค่ากระเบื้อง
- ยังไม่มีอัตราจริงจากช่าง เมื่อได้ตัวเลขจริงให้แก้ที่ `config.js` ที่เดียว

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | หน้าเว็บและแบบฟอร์ม 5 ขั้นตอน |
| `styles.css` | รูปแบบหน้าจอ เน้นมือถือ |
| `config.js` | อัตราตัวอย่างทั้งหมด แก้ที่นี่ที่เดียว |
| `calc.js` | สูตรคำนวณช่วงราคา จำนวนวัน และจำนวนกล่อง |
| `app.js` | การทำงานของแบบฟอร์ม หน้าผลลัพธ์ และปุ่ม LINE / คัดลอก |
| `shots/` | ภาพตัวอย่างหน้าจอจากทดสอบบนมือถือ |

## วิธีแก้ราคาใน `config.js`

เปิดไฟล์แล้วแก้ค่าในออบเจ็กต์ `TILE_ESTIMATOR_CONFIG` แล้วรีเฟรชหน้าเว็บ ไม่ต้องติดตั้งโปรแกรมเพิ่ม

ค่าที่มักจะต้องปรับเมื่อได้ราคาจริงจากช่าง:

- `baseLaborPerSqm` ค่าแรงพื้นฐานต่อตารางเมตร ตามขนาดกระเบื้อง `60x60`, `30x30`, `10x10`, `60x120`
- `locationMultiplier` ตัวคูณตามบริเวณ เช่น ห้องน้ำสูงกว่าพื้นโถง เพราะตัดเศษเยอะ
- `siteMultiplier` ตัวคูณตามหน้างาน บ้านชั้น 1 / บ้านชั้นบน / คอนโด
- `siteProductivity` และ `sqmPerDay` ใช้ประมาณจำนวนวันทำงาน
- `travelCostPerKm` ค่าเดินทางตัวอย่าง บาทต่อกิโลเมตร คิดไป-กลับอัตโนมัติ
- `minimumJobCharge` ค่าแรงขั้นต่ำต่องาน สำหรับงานเล็ก เช่น ผนังครัว 3 ตร.ม.
- `addons.demolishPerSqm` และ `addons.levelingPerSqm` ค่ารื้อของเก่าและปรับระดับพื้น
- `m2PerBox`, `kgPerBox` ใช้ประมาณจำนวนกล่องและน้ำหนักที่ต้องขน
- `shopName`, `phonePlaceholder`, `bannerText` ชื่อร้าน เบอร์ และข้อความเตือน

สูตรคร่าว ๆ:

1. ค่าแรงหลัก = พื้นที่ × ค่าแรงพื้นฐานตามขนาดกระเบื้อง × ตัวคูณบริเวณ × ตัวคูณหน้างาน
2. บวกค่ารื้อหรือปรับระดับพื้น ถ้าลูกค้าเลือก
3. ถ้ายังต่ำกว่าค่าแรงขั้นต่ำ ให้ใช้ค่าแรงขั้นต่ำ
4. ค่าเดินทาง = ระยะทางขาเดียว × 2 × อัตราต่อกิโลเมตร × จำนวนวันทำงาน
5. ช่วงราคาที่โชว์ = ยอดรวม × 0.90 ถึง × 1.15 แล้วปัดเป็น 100 บาท (ล่างปัดลง บนปัดขึ้น) แต่ช่วงล่างจะไม่ต่ำกว่าค่าแรงขั้นต่ำต่องาน
6. จำนวนกล่อง = พื้นที่ × 1.10 (เผื่อเศษ) หารด้วยพื้นที่ต่อกล่อง แล้วปัดขึ้น

## วิธีรันบนเครื่องตัวเอง

ถ้าเปิดไฟล์ตรง ๆ จากเครื่องบางเบราว์เซอร์อาจจำกัดการทำงาน แนะนำให้เปิดผ่านเว็บเซิร์ฟเวอร์เล็ก ๆ

ในโฟลเดอร์นี้ รัน:

```bash
python3 -m http.server 4173
```

แล้วเปิด [http://127.0.0.1:4173/](http://127.0.0.1:4173/)

## วิธีขึ้น GitHub Pages

1. สร้างรีโพซิทอรีใหม่บน GitHub แล้วอัปโหลดไฟล์ในโฟลเดอร์นี้ขึ้นไป (ไม่ต้องมี `tests/` ก็ได้)
2. ไปที่ Settings → Pages
3. ที่ Source เลือกสาขา `main` และโฟลเดอร์ `/ (root)`
4. บันทึก แล้วรอสักครู่ เว็บจะเปิดที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อรีโพ>/`

ไม่ต้องตั้ง GitHub Actions และไม่ต้องรันคำสั่ง build

ถ้าอยากให้เปิดที่โดเมนหลักของบัญชี ให้ตั้งชื่อรีโพว่า `<ชื่อผู้ใช้>.github.io` แล้ววางไฟล์ไว้ที่รากของรีโพ

## การทดสอบในเครื่องนี้

มีสคริปต์ตรวจการคำนวณและเปิดหน้าเว็บขนาดมือถือ 390×844 ไว้ใน `tests/` สำหรับคนที่พัฒนาต่อ ไม่จำเป็นตอนขึ้น GitHub Pages

```bash
node tests/calc.test.js
# และรัน Playwright ตามสคริปต์ใน tests/verify.mjs
```
